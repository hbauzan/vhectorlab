## Cómo ejecutar un nuevo Roadmap Activo

1. Crear el documento de especificación técnica del nuevo epic en esta carpeta.
2. Dividir en Slices verticales con contratos matemáticos y tests antes de implementar (TDD).
3. Fuente de verdad del código: `CHANGELOG.md`, `CONTEXT.md`, `architecture_spec.md`, `main` @ SemVer en `manifest.json`.
